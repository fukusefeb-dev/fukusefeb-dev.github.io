MultiMovie ヘルプ

好きなページを最大4画面で同時に流せるアプリです。

タイルに追加する

タイルの「URL を追加」から貼り付けるか、Safari や動画アプリの共有ボタンから「MultiMovie」を選びます。共有したときは、次に MultiMovie を開いたときに、入れるタイルを選べます。

音声を切り替える

タイルの上の帯のスピーカーを押します。音が出るタイルは常に1つだけで、黄色の枠で示します。切り替えた直後に、前のタイルの映像が1〜2秒止まることがあります。

拡大する

タイルの上の帯をダブルタップするか、「…」のメニューから「拡大」を選びます。

テレビに映す

HDMI アダプタが最も安定します。AirPlay の画面ミラーリングは、通信状態によって遅れたり画質が落ちたりします。テレビに映しているあいだ、スマホはリモコンになります。スマホの画面はロックしないでください。ロックすると映像が止まります。暗くしたいときは「省電力表示」を使ってください。

映像が再生されないとき

  • 「…」のメニューから再読み込みしてください。
  • サイトによっては、同時再生や埋め込みに対応していないことがあります。「PC版で表示」を試してください。

Pro（サブスクリプション）

解約やプランの変更は、設定アプリの Apple ID > サブスクリプションから行えます。機種変更などのあとは、アプリの設定から「購入を復元」を押してください。

iCloud 同期

レイアウトは、同じ Apple ID の iPhone と iPad のあいだで同期します。反映まで少し時間がかかることがあります。
