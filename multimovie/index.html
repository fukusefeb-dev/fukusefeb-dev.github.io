MultiMovie ヘルプ

好きなページを最大4画面で同時に流せるアプリです。

タイルに追加する

タイルの「URL を追加」から貼り付けるか、Safari や動画アプリの共有ボタンから「MultiMovie」を選びます。共有したときは、次に MultiMovie を開いたときに、入れるタイルを選べます。

音声を切り替える

タイルの上の帯のスピーカーを押します。音が出るタイルは常に1つだけで、黄色の枠で示します。切り替えた直後に、前のタイルの映像が1〜2秒止まることがあります。

分割を選ぶ

上のバーの左のボタンから、1画面・2分割・3分割・4分割・「大1＋小3」を選べます。並べ方は画面の向きに合わせて、映像がいちばん大きくなるように変わります（縦向きの iPhone では縦に並びます）。3分割以上は Pro の機能で、無料版では広告を見ると3時間使えます。

タイルの中でページを移動する

タイルの「…」のメニューから、戻る・進むができます。見たいページまで進んだら「いまのページを保存」を押すと、そのページがタイルに保存されます。

履歴とお気に入り

タイルの編集画面の「履歴・お気に入りから選ぶ」で、前に入れた URL を選べます。履歴とお気に入りはその端末に保存され、ほかの端末には同期されません。

レイアウトを共有する

レイアウトの一覧で、行を左にスワイプ（または長押し）して「共有」を選ぶと、リンクと QR コードが出ます。受け取った人は、開くページを確かめてから自分の MultiMovie に追加できます。リンクには各タイルの URL が入るので、ログイン情報などが含まれていないか確かめてから共有してください。

没入表示とスリープタイマー（Pro）

上のバーの「…」から選べます。没入表示はタイルの帯を隠して映像を大きくします（上端のつまみを押すとバーが戻ります）。スリープタイマーは、指定した時間がたつとすべてのタイルを止めます。

拡大する

タイルの上の帯をダブルタップするか、「…」のメニューから「拡大」を選びます。

テレビに映す

HDMI アダプタが最も安定します。AirPlay の画面ミラーリングは、通信状態によって遅れたり画質が落ちたりします。テレビに映しているあいだ、スマホはリモコンになります。スマホの画面はロックしないでください。ロックすると映像が止まります。暗くしたいときは「省電力表示」を使ってください。画面のふちが切れるときは、リモコン画面の「テレビの表示」で表示サイズを小さくできます。

映像が再生されないとき

  • 「…」のメニューから再読み込みしてください。
  • それでも再生できないときは、「…」のメニューの「再生できないときは報告」からお知らせください。
  • サイトによっては、同時再生や埋め込みに対応していないことがあります。「PC版で表示」を試してください。

Pro（サブスクリプション）

解約やプランの変更は、設定アプリの Apple ID > サブスクリプションから行えます。機種変更などのあとは、アプリの設定から「購入を復元」を押してください。

iCloud 同期

レイアウトは、同じ Apple ID の iPhone と iPad のあいだで同期します。反映まで少し時間がかかることがあります。
